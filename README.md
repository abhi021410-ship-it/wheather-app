# 🌤️ Simple Weather Finder

A very simple weather app that lets you type a **city name** and instantly see:

- City
- Current temperature (°C)
- Weather description (clear sky, clouds, rain, etc.)

Built using **HTML, CSS, jQuery**, and the **OpenWeather API via RapidAPI**.

---

## 🚀 Features

- 🔎 Search weather by city name  
- 🌡️ Shows temperature in °C  
- ⛅ Displays a short weather description  
- ⚡ Uses Ajax (no page reload)  
- 💻 Very small and beginner-friendly codebase

---

## 🛠️ Tech Stack

- **HTML** – basic page structure  
- **CSS** – light blue background and simple styling  
- **jQuery (Ajax)** – API call and DOM updates  
- **OpenWeather13 API (RapidAPI)** – live weather data
